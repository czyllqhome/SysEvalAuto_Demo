# Markdown PRD 导入

## 使用方式

在“描述系统”页面选择“从已有 PRD 导入”，上传 UTF-8（含 BOM）`.md` 文件，预览后点击“解析并自动填充”。该操作使用组织配置的 OpenRouter 模型；上传预览、页面刷新和普通保存不调用模型。

系统检查全部八个主题：建设目标、功能与范围、涉及部门、负责人及角色、业务流程、数据与接口、交付约束、边界与验收。有依据的内容自动填入仍为空且解析期间未编辑的字段。未找到的主题保持空白，部分信息只填已找到部分，原文矛盾单独展示，不推测补齐。

导入面板显示当前值、提取值、原文行号及证据、缺失项和冲突。结果是模型提取的待核对草稿，并不自动确认等级、应用说明、控制或基线。原文语言保持不变，界面支持中文和英文。

## 更新、撤销与确认

- 已有人工内容保留。选择字段后可以替换、编辑合并或明确清空。
- 新版 PRD 不会自动覆盖上一版内容，可批量选择仍未被人工修改的导入字段。
- 新版没有找到旧内容时保留当前值。明确取消某项要求需选择更新或清空后应用。
- 撤销以应用后的值和编辑计数为条件；后续修改过的字段跳过，撤销本身不能被误当成新的填充操作。
- 已确认过等级、应用说明或进入下游阶段时，应用内容变更必须勾选修订影响提示。系统创建新的评估修订，清除当前分级、说明和下游成果指针，保留历史记录。必须重新确认等级与说明，双方不能沿用旧基线确认。
- 系统名称只提供有证据的候选，用户主动选择后才修改已有名称。

## 实现与接口

服务端模块：`backend/app/prd_imports.py`。界面：`frontend/src/PrdImport.tsx`。

| 接口（前缀 `/api/v1`） | 内容 |
| --- | --- |
| `POST /systems/{id}/prd-imports` | JSON 上传：`filename`、`markdown`、当前系统 `version`；返回系统详情及 `import_id` |
| `GET /systems/{id}/prd-imports` | 导入文档历史 |
| `GET /systems/{id}/prd-imports/{import_id}` | 原文、最新任务、八字段结果、应用记录和修订提示 |
| `POST /systems/{id}/jobs` | `kind=prd_import_extraction`、`mode=openrouter`、`language`、`version`；`reparse=true` 强制重新解析 |
| `POST /systems/{id}/prd-imports/{import_id}/apply` | `job_id`、`values`、`version`；可选 `acknowledge_revision`、`use_name` |
| `POST /systems/{id}/prd-imports/{import_id}/undo` | `application_id`、`version`，必要时附 `acknowledge_revision`；返回跳过字段 |

写入复用原有 CSRF、对象权限、系统版本检查和 `Idempotency-Key`。供应商不能读取导入原文；只读人员不能上传、解析或应用。后台完成时重新验证发起者仍有编辑权限。

新增 `prd_imports` 和 `prd_import_applications` 表，使用增量迁移 `prd_imports`。提取快照保存在现有 `ai_jobs`；字段来源保存在草稿 `block_sources`，随确认后的 `ContextRevision.source` 保留，再通过业务条目的 `source_blocks` 追溯。导入不会删除 `.syseval/assessment.db` 中的历史数据。

模型请求使用带稳定行号的原文片段，覆盖 Markdown 标题、段落、列表和表格。模型返回固定八字段和独立名称候选；每项具有 `found/missing/conflict`、正文及证据。服务端验证完整结构、长度、来源 ID 与精确摘录。联系人脱敏后验证模型实际看到的证据，行号仍指向原始文件。有效引用不代表模型归纳绝对正确，用户仍需核对。

模型设置新增第十二个提示词模板“PRD 导入提取”。既有组织配置自动继承新模板，保留已编辑的其他模板。队列固定模型配置和模板；相同文档、评估修订与配置的成功结果可复用，强制重新解析会新建任务。任务租约、过期来源拒绝、失败重试和用量记录沿用现有 worker。

## 限制与运维

- 单个文件上限 60,000 字节；带来源信息的序列化片段上限 85,000 字节，完整模型输入仍受既有 100,000 字节限制。过多短行也可能触发上限，不静默截断。
- 每个描述字段最多 10,000 字符，全部字段最多 50,000 字符。原文预览为转义文本，不执行 HTML、代码或外链。
- 当前不支持长文分段合并、多文件、PDF、Word、OCR 或自动填写分级问卷。
- 默认本地启动自动创建缺失的新表；禁用自动建表的部署须先执行增量迁移，再启动新版 API 和 worker。
- 模型失败保留原文及人工草稿，不自动切换到规则生成。

离线回归使用临时数据库与模拟模型响应，覆盖来源校验、空白填充、人工编辑、并发、更新、撤销、权限和修订；不代表已验证真实模型质量或外部提供商可用性。
